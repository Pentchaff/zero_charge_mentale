# Pas de suivi individuel visible par l'autre

L'app montre ce qui reste à faire dans le foyer, mais jamais qui a fait quoi. Pas d'historique par membre, pas d'alerte du type « elle n'a pas fait X ». Un suivi par personne transformerait l'app en outil de contrôle dans le couple, ce qui est incompatible avec le principe zéro culpabilité (ADR 0001). Pour les médicaments, le rappel est personnel et ne remonte pas au conjoint sauf décision explicite du membre concerné.
