# Trois axes de progression, un seul compteur

Les tâches accomplies alimentent un compteur cumulatif unique qui ne recule jamais (ADR 0008). Ce compteur débloque des récompenses sur trois axes :

1. **Rikki** : il grandit, nouvelles animations, nouveaux comportements.
2. **Avatar** : nouveaux vêtements, accessoires, coiffures.
3. **Maison** : nouveaux meubles, décorations, améliorations des pièces.

Les récompenses sont entrelacées sur les paliers pour que chaque tranche de quelques tâches donne quelque chose de visible. Le membre n'a pas à choisir où investir : tout vient avec la progression.
