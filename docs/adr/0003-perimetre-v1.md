# Périmètre de la V1 : les tâches du quotidien, pas les habitudes

La V1 couvre seulement les tâches de quatre domaines : logement, linge, repas et courses, soins de base (manger, se laver, médicaments). Elle démarre sur un foyer type pré-rempli, sans onboarding long. Les habitudes, l'administratif, le budget et les rendez-vous en sont exclus : les habitudes feraient dériver l'app vers un tracker (séries, objectifs) contraire à l'ADR 0001, et l'administratif (ponctuel, à échéance) demande un modèle différent.
