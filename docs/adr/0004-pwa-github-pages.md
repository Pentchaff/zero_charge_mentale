# PWA statique hébergée sur GitHub Pages

L'app est une application web installable (PWA) servie par GitHub Pages : gratuite, sans store, installable sur le téléphone. GitHub Pages ne sert que des fichiers statiques, donc l'app n'a pas de serveur à elle. Sur iPhone, les notifications ne marchent que si l'app est ajoutée à l'écran d'accueil.
