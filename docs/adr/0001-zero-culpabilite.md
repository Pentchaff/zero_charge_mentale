# Zéro culpabilité

L'app s'adresse d'abord à une personne en dépression. Aucune fonctionnalité ne peut donc produire de la culpabilité : pas de compteur de retard, pas de série de jours, pas de rouge, pas de « N tâches en retard », pas de score. Une tâche ratée revient plus tard, sans reproche. Toute fonctionnalité nouvelle doit passer ce filtre, même si la gamification paraît être la voie évidente.
