# Mode 🪫 : zéro tâche, juste de la présence

Quand un membre déclare son énergie à 🪫, l'app ne propose aucune tâche. Elle montre seulement le compagnon qui fait quelque chose de réconfortant. Le message implicite : « Aujourd'hui, tu n'as rien à faire. Ton écureuil est là. » C'est le moment le plus important de l'app. Si elle forçait une tâche même légère, elle échouerait dans son rôle (ADR 0001).
