# Les émotes se jouent entre les personnages, et Rikki porte celles qui attendent

Une émote n'est plus un emoji qui s'envole : les personnages font vraiment le geste. Si l'autre membre a l'app ouverte, son avatar est dans la pièce (ADR 0011) : l'avatar de l'envoyeur marche jusqu'à lui, ils s'enlacent, se font un bisou ou un pat pat sur la tête, puis chacun retourne à ce qu'il faisait. Les deux téléphones jouent la même scène, chacun de son point de vue.

Si l'autre n'est pas là, on ne fait pas apparaître son avatar pour jouer le geste, même brièvement : ce serait un fantôme qui laisse croire qu'il est en ligne, ce que la présence stricte interdit (ADR 0011, ADR 0025). C'est Rikki qui porte le geste : à l'envoi, le membre le lui confie (il serre Rikki contre lui, lui fait un bisou, une caresse) ; à la réception, Rikki le rend (câlin de côté, bisou sur la joue, pat pat perché sur la tête).

## Conséquences

- Pas de nouvelle donnée synchronisée : les positions et les activités de l'autre avatar sont calculées sur chaque téléphone. Seuls la présence et l'émote elle-même transitent, comme avant.
- Pendant un geste, rien ne l'interrompt : ni une nouvelle prochaine action, ni le changement de pièce qui suit « Fait ».
