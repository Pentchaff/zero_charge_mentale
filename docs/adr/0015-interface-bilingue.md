# Interface bilingue français / japonais

La première utilisatrice est japonaise. Lui imposer le français pour une app qui réduit la charge mentale serait une contradiction. L'interface est en japonais pour elle et en français pour l'aidant. La langue est choisie par membre, pas par foyer.

## Conséquences

- L'internationalisation (i18n) est intégrée dès le début, pas ajoutée après.
- Les tâches et aide-mémoire du foyer type ont une version française et une version japonaise.
- Les tâches personnalisées par l'aidant sont dans sa langue. Elles devront soit être traduites manuellement, soit le compagnon (Gemini, ADR 0009) peut servir de traducteur contextuel.
- Le compagnon parle dans la langue du membre.
