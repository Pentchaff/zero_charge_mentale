# Tâches personnelles : chacun pour soi, sans regard de l'autre

Les soins de base (se brosser les dents, manger, se doucher) ne se partagent pas : si l'un les fait, l'autre n'en est pas dispensé. Le pot commun ne convient donc pas. Une tâche peut être « chacun pour soi » : son avancement est suivi séparément pour chaque membre, et cet avancement n'est affiché nulle part, ni à l'autre ni au membre lui-même (ADR 0005). Proposé dans la v0, à confirmer au cadrage.

## Options écartées

- Une copie de chaque tâche réservée à chaque membre (ADR 0016) : double le foyer type et oblige l'aidant à tout maintenir en deux exemplaires.
